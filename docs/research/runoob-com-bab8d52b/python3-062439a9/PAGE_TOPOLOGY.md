# Python3 Page Topology

1. Header shell
   - Brand / tutorial title area
   - Search box
   - Top navigation tabs
2. Content layout
   - Left sidebar with tutorial section navigation

3. Interaction model
   - Mostly static article reading experience

- Page heading
