# Page Topology

## Layout hierarchy

1. Top-level shell
   - White-to-off-white page on a warm gray background
   - Header includes logo, search box, then green navigation bar
2. Main content
   - Several tutorial section panels stacked vertically
   - Each panel has a section title and a two-column card grid
3. Interaction model
   - Static list layout with hover transitions
   - Mostly click-driven links to tutorial pages
   - No complex scroll behavior or modal patterns

## Styling notes

- Header background is nearly white with subtle borders.
- Navigation uses a muted sage green band.
- Course cards are soft gray with outer border and small rounded corners.
- Each icon is a colored rounded square with a short badge.
- Typography is bold, utilitarian, and tuned for Chinese text.
